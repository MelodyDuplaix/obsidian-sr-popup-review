# Popup Review for Spaced Repetition

[English README](README.md)

Obsidianを開かなくても [Spaced Repetition](https://github.com/st3v3nmw/obsidian-spaced-repetition) の暗記カードを復習できるプラグインです。一定間隔でデスクトップ右下に小さな最前面ポップアップが現れ、その場で「問題を読む → 答えを見る → Again / Hard / Good / Easy で評価」まで完結します。

評価は Spaced Repetition プラグイン**自身のレビュー処理**（レビューモーダルのボタンと同じコードパス）を通して書き込まれるため、スケジュールデータの整合性は本家と完全に同一です。SM-2 / FSRS の再実装はしていません。

Spaced Repetition **v1.15.4** で動作確認しています。

## 動作の流れ

1. 設定した間隔（デフォルト2時間）ごとに、期限が来ているカードがあるかチェックします。
2. あれば、プライマリディスプレイ右下にポップアップが出ます。**フォーカスは奪いません**。Obsidianは最小化したままでOKです。
3. 問題を読み、**答えを見る**（または `Space`）で答えを表示し、4つのボタン（または `1`〜`4` キー）で評価します。
4. 評価は Spaced Repetition 経由で保存され、ポップアップは閉じます。評価せずに閉じた場合は何も書き込まれず、カードは期限のまま残ります。

## 必要環境

- Obsidian **デスクトップ版**（Windows / macOS / Linux。ポップアップにElectronウィンドウを使うためモバイル非対応）
- [Spaced Repetition](https://github.com/st3v3nmw/obsidian-spaced-repetition) プラグイン（インストール済み・有効）

## インストール

### コミュニティプラグインブラウザから（推奨）

1. 設定 → コミュニティプラグイン → 閲覧 を開く
2. 「**Popup Review**」で検索して **Popup Review for Spaced Repetition** をインストール
3. 設定 → コミュニティプラグイン で有効化

### 手動

1. [最新リリース](https://github.com/uzusio/obsidian-sr-popup-review/releases) から `main.js` / `manifest.json` / `styles.css` をダウンロード
2. `<あなたのvault>/.obsidian/plugins/sr-popup-review/` に配置
3. Obsidianをリロードして **Popup Review for Spaced Repetition** を有効化

## ポップアップの使い方

| 操作 | 効果 |
| --- | --- |
| **答えを見る** をクリック / `Space` か `Enter` | その場で答えを表示 |
| **Again / Hard / Good / Easy** をクリック / `1`〜`4` キー | 評価を保存して閉じる |
| **✕** をクリック / `Esc` | 何も保存せずに閉じる |
| **⋯**（✕の左）をクリック | オプションメニュー：ノートを開く（カードの出典ノートを該当行で開く。ポップアップは開いたまま）／再開するまで停止／30分・1時間・3時間のスヌーズ |
| ヘッダをドラッグ | ポップアップを移動 |

評価ボタンのラベルは Spaced Repetition 側で設定したものがそのまま使われます。Spaced Repetition の設定「Show next review time in the review buttons」がオンのとき、各ボタンの2段目にそのボタンを押した場合の次の間隔（例: `(3日)`）を表示します。カード本文はマークダウンとして描画され、穴埋め（cloze）のマスクも通常のレビューモーダルと同じです。

コマンドパレットの **「今すぐレビューポップアップを表示」** で、任意のタイミングでポップアップを出すこともできます。

設定で **グローバルショートカット** を設定すると、Obsidian がバックグラウンドにあってもキーの組み合わせでポップアップを表示できます（Obsidian 本体は前面に出ず、ポップアップにキーボードフォーカスが移るのですぐキーで回答できます）。

設定で **ポップアップをローカルページに表示** をオンにすると、ポップアップと同じ表示をローカルの Web ページ（既定は `http://127.0.0.1:27280/`）に映します。この URL を OBS のブラウザソース、画面共有するブラウザウィンドウ、別モニターなどで開くと、ポップアップの表示（答えの表示・評価・メニュー・スクロール・サイズ変更）にそのまま追従し、ポップアップが出ていない間は何も表示されません（透明）。ポップアップはページの幅か高さのいっぱいまで自動で拡大・縮小されます（左上寄せ）。OBS では **ブラウザ** ソースに URL を登録し、好きな大きさで配置してください。

自動ポップアップを一時停止したいときは、**右下ステータスバーのベルアイコン**、コマンド **「ポップアップの一時停止を切り替え」**、設定のトグルのどれでも切り替えられます（3つとも同じスイッチです）。停止中でも手動の「今すぐ表示」コマンドは動きます。

## 設定

| 設定 | デフォルト | 説明 |
| --- | --- | --- |
| 言語 | Obsidianの設定に従う | このプラグインの表示言語（English / 日本語） |
| ポップアップを一時停止 | オフ | 自動ポップアップを一時停止（右下ステータスバーのベルアイコン・コマンドでも切替可） |
| グローバルショートカット | 未設定 | Obsidian がバックグラウンドでもポップアップを表示できるシステム全体のキーの組み合わせ |
| ポップアップをローカルページに表示 | オフ | ポップアップの表示を `http://127.0.0.1:<ポート>/` に映す（OBS のブラウザソース・画面共有向け）。オンにするとポート（既定 27280）と URL のコピーボタンが表示され、起動中かポート使用中かも表示される |
| ポップアップ間隔（分） | 120 | ポップアップを出す間隔（最小5分） |
| ポップアップ停止時間帯 | オン・01:00〜09:00 | トグル＋時間範囲の1行UI。この時間帯はポップアップを出さない。日付をまたぐ範囲も可 |
| 自動クローズ（秒） | 90 | 無操作のポップアップを閉じる（何も書き込まない）。0で無効 |
| 新規カードの導入 | 1日の上限枚数まで（10枚） | 未レビューの新規カードを期限カードとの枚数の比率で混ぜて出す（1日の上限枚数までの場合は、その日の残り枠だけを新規カードの枚数とみなす）：出さない／1日の上限枚数まで／無制限 |
| 新規カードの割合を固定する | オフ | オンにすると、新規と復習の両方が残っているとき、下の割合で新規カードを選ぶ（オフは残りの枚数に比例）。「出さない」以外のときに表示 |
| 新規カードの割合 | 67% | 固定をオンにすると表示されるスライダー（5〜95%）。67% なら 3 枚中およそ 2 枚。1 日の上限に達したあとは復習だけになる |
| デッキ順を無視してランダムに出題 | オン | カード枚数で重み付けしたランダムなデッキから出題（全カードがほぼ等確率）。オフでSpaced Repetition本来のデッキ順 |
| フルスクリーンアプリ中はポップアップを出さない | オン | ゲーム・プレゼン・F11全画面などの間は見送り、終了後1分以内に表示。Windows専用 |
| デッキフィルタ | 全デッキ | 全デッキ / リストのデッキのみ |
| デッキリスト | — | デュアルリスト形式：「既存のデッキ」⇄「対象のデッキ」を追加/除外ボタン（ダブルクリックも可）で移動。対象デッキはサブデッキにも適用。対象が空の間は全デッキ |
| デッキ名を表示 | オン | ヘッダにデッキパスを表示 |
| 起動直後にチェック | オフ | Obsidian起動の約15秒後に1回チェック |

設定画面にはSpaced Repetition連携の状態（動かない場合はその理由）も表示されます。

「今日」（今日の枚数・新規カードの 1 日の上限）は Spaced Repetition の「1日の開始時刻」（Start of day）設定に従います。SR 1.15.4 では不具合により時・分・秒のどれかが 0 だと設定が効かないため、5 時区切りにするなら `05:01:01` のように指定し、Obsidian を再起動してください。

## 外部ツールとの連携（Obsidian CLI）

ポップアップを開いている間にスクリプトや AI ツールがカードのノートを書き換えると、採点時に Spaced Repetition がカードを見つけられなくなることがあります。Obsidian のコマンドラインインターフェース（CLI）用の 2 つのコマンドで、書き換える前に問い合わせられます。使うには Obsidian の設定で CLI を有効にしてください（Obsidian の起動中のみ応答します）。

`obsidian sr-popup-review:state` — ポップアップのいまの状態:

```json
{"state":"showing","path":"Cards/Spanish.md","original":"hola::hello\n<!--SR:!2026-10-08,3,250-->"}
```

`state` は `idle`（何もしていない）・`preparing`（カードを選んでいる）・`showing`（カードを表示中）・`writing`（採点を書き込み中）のいずれかです。`path` / `original`（表示中のカードの問題ブロック全文）は `showing` / `writing` のときだけ入ります。

`obsidian sr-popup-review:check path=<パス> old=<文字列> new=<文字列>` — そのノートで `old` を `new` に 1 か所置き換えると、表示中のカードに影響するか:

```json
{"result":"safe","reason":"the open card's text stays intact"}
```

- 別のノートの書き換え、またはポップアップが開いていないときは `safe`
- 表示中のカードのノートでは、`old` がちょうど 1 か所あり、書き換え後も問題ブロックがそのまま 1 か所だけ残るときだけ `safe`
- 判別できないとき（カードを選んでいる・採点を書き込み中・ノートや文字列が見つからない など）は `unsafe`。コマンド自体が失敗したときも `unsafe` と同じに扱ってください
- `path` は vault 内の相対パスで渡します（絶対パスは `unsafe`）
- `old` / `new` の中の改行は `\n`、タブは `\t`、バックスラッシュは `\\` と書きます。削除を確かめるときは `new` を省略します

### 準備

- Obsidian の設定で CLI を有効にします。Obsidian が起動している必要があります。
- Windows の Git Bash などのシェルから呼ぶときは `obsidian.com` と拡張子付きで呼びます。`obsidian` だけだと GUI 版の実行ファイルに解決され、出力が返りません。
- 複数の vault を開いているときは、すべてのコマンドに `vault=<vault 名>` を付けます。

### 連携の手順（どのツールでも同じ）

1. ノートを書き換える直前に `check` を呼ぶ
2. `safe` なら書く
3. `unsafe`・コマンドの失敗・解釈できない応答のときは書かずに待ち、`state` が `idle`（ポップアップを閉じた状態）になってからやり直す
4. 書いた後にファイルを読み直し、自分の変更が残っていることを確かめる。`check` と書き込みの間に採点が保存されると、Spaced Repetition の書き込みに上書きされることがあるため

ファイル全体を書き直すときも `check` で判定できます。`old` に今の全文、`new` に新しい全文を渡します（OS のコマンドライン長の上限に注意）。または `state` が `idle` のときだけ書く方法もあります。

### 例: Claude Code の hook

[`examples/claude-code/sr-popup-guard.mjs`](examples/claude-code/sr-popup-guard.mjs) は、Claude Code の `PreToolUse` hook 用の依存なしの Node スクリプトです。`.claude/settings.json` に登録します。

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "node /path/to/sr-popup-guard.mjs" }
        ]
      }
    ]
  }
}
```

Claude Code を動かす環境で、環境変数 `SRPR_VAULT_ROOT` に vault の絶対パスを設定します（任意で `SRPR_VAULT_NAME`。`vault=` として渡されます）。

- `SRPR_VAULT_ROOT` 配下の `.md` ファイルだけを確かめ、それ以外の編集は通します。`SRPR_VAULT_ROOT` が未設定なら何もしません。
- 通常の `Edit` は `check` に送ります。`Write` と `replace_all` 付きの `Edit` は複数箇所に触れるため `state` で判断します。`idle`（または別のノートを表示中）なら通し、`preparing`・`writing`、または表示中のカードが同じノートのときは止めます。
- 止めるときは、Claude に「ポップアップを閉じてから同じ編集をやり直す」よう伝えます。
- Obsidian が起動していないとコマンドは失敗します。ポップアップは Obsidian の起動中にしか出ないので、その場合は書いても問題ないのですが、このスクリプトは安全側に倒して止めます。そうしたくなければスクリプトを書き換えてください。

## データの安全性

- 評価は Spaced Repetition 自身のレビューシーケンサーを通ります。モーダルのボタンを押した場合と**同一の書き込み**です（スケジュールコメント、兄弟カードのbury、ロードバランス、FSRS/SM-2すべて含む）。
- このプラグインは Spaced Repetition の内部実装に依存するため、**使用する内部要素を毎回すべて検査**します。将来のバージョンで内部が変わった場合は通知を出して機能を停止し、**不明なコードパスで書き込むことは決してありません**。
- ポップアップを閉じた・自動クローズされた場合は何も書き込まれません。
- **通信について**: 「ポップアップをローカルページに表示」がオンのときだけ、`127.0.0.1`（このPC内）で待ち受けます。PCの外へは何も送信しません。同じPC上の他のアプリからは、そのページを通じて表示中のカードの内容と vault 内の画像を読めます。

## 既知の制限

- ポップアップが出るのはObsidianの起動中のみ（最小化はOK）
- ポップアップは自前の最前面ウィンドウであり、OSの通知ではありません。通知センターには残らず、集中モード（応答不可）そのものは無視されます。フルスクリーンアプリ・プレゼン中の見送りは別機能として用意しています（設定参照）
- 表示位置は現状プライマリディスプレイの右下固定です
